Events

The container element dispatches custom events that you can listen to:

Event Name Triggered When Event Detail
puffin:enter Pointer enters the image container. e.detail.puffin (the Puffin instance)
puffin:leave Pointer leaves the image container. e.detail.puffin (the Puffin instance)
puffin:click The image container is clicked. e.detail.puffin, e.detail.originalEvent
customEvent Dispatched alongside any event above for backward compatibility. None

Example

{% highlight javascript %} const container = document.querySelector('.puffin-container'); container.addEventListener('puffin:enter', (event) => { console.log('Hovered!', event.detail.puffin); }); container.addEventListener('puffin:leave', (event) => { console.log('Mouse left the container'); }); container.addEventListener('puffin:click', (event) => { console.log('Clicked!', event.detail.originalEvent); }); {% endhighlight %}
