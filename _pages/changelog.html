Changelog

2.0.0

  • Zero Runtime Dependencies: Removed Lodash and GSAP dependencies in favor of native ES6+ and hardware-accelerated CSS transitions.
  • Vite 8: Switched build system to modern Vite 8 with ESM, UMD, and CSS asset outputs.
  • BiomeJS: Added Biome for lightning-fast formatting and linting.
  • Custom Events: Added puffin:enter, puffin:leave, and puffin:click events.
  • Lifecycle Support: Added destroy() method to clean up listeners and DOM elements.
  • Bug Fixes: Fixed string sorting issue in getMinimumPart/getMaximumPart, eliminated flickering on hover by switching to mouseenter, and cleaned up uninitialized style properties.
  • Size Optimization: Reduced bundle size from 130+ KB to ~6 KB (~2 KB gzipped).
