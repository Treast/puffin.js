API

Puffin Options

Property Type Informations
selector string Optional. CSS selector of the container (e.g. #myContainer)
element HTMLElement Optional. Direct DOM element reference (alternative to selector)
image string URI of the image
overlay string|false Optional. HTML or text displayed in the overlay upon hover. Default is disabled
duration number Optional. Default transition duration in seconds. Default is 0.4
delay number Optional. Default enter delay in seconds. Default is 0
easing string Optional. CSS transition timing function. Default is 'cubic-bezier(0.25, 1, 0.5, 1)'
parts PuffinPart[] Array of slice configurations. See below for more information.

Puffin Methods

Method Description
destroy() Removes event listeners, removes generated slices/overlay from DOM, and resets container styles.

PuffinParts

Property Type Informations
x number Target horizontal pixel offset upon hover. If negative, the slice moves left; if positive, it moves right.
y number Target vertical pixel offset upon hover. If negative, the slice moves up; if positive, it moves down.
height number Height of the slice in pixels.
width number Width of the slice in pixels.
delay number Optional. Delay override before moving this slice. Default is the parent's delay.
duration number Optional. Duration override for this slice. Default is the parent's duration.
easing string Optional. Easing override for this slice. Default is the parent's easing.
