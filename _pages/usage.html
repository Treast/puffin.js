Usage

Import

You can import puffin.js using ES6 modules (Vite, Webpack, Rollup):

{% highlight javascript %} import Puffin from 'puffin.js'; {% endhighlight %}

Or load it directly in HTML via script tag:

{% highlight html %} {% endhighlight %}

How to use ?

A basic usage looks like this:

{% highlight javascript %} const puffin = new Puffin({ selector: '.puffin-container', image: './assets/images/puffin.png', duration: 0.4, delay: 0, easing: 'cubic-bezier(0.25, 1, 0.5, 1)', overlay: "Demonstration puffin.js", parts: [ { x: -80, y: -100, height: 150, width: 120, }, { x: -90, y: 60, height: 150, width: 170, delay: 0.1, duration: 0.4, }, { x: 140, y: 90, height: 210, width: 160, delay: 0.2, duration: 0.5, }, { x: 120, y: -60, height: 160, width: 150, delay: 0.3, duration: 0.6, }, ], }); {% endhighlight %}

Cleanup / Destroy

When unmounting a component or navigating dynamically in a Single Page App (SPA):

{% highlight javascript %} puffin.destroy(); {% endhighlight %}

Options

Puffin

Property Type Informations
selector string Optional. Container selector (e.g. .my-class)
element HTMLElement Optional. Container DOM element directly
image string URI or path of the image
overlay string|false Optional. HTML/text displayed on hover overlay. Default is disabled
duration number Optional. Default duration for all slices. Default is 0.4
delay number Optional. Default enter delay for all slices. Default is 0
easing string Optional. CSS transition timing function. Default is 'cubic-bezier(0.25, 1, 0.5, 1)'
parts PuffinPart[] Slice definitions. See below.

PuffinParts

Each slice represents an image fragment that dislocates upon hover with parallax:

Property Type Informations
x number Horizontal offset upon hover (negative = left, positive = right).
y number Vertical offset upon hover (negative = up, positive = down).
height number Height of the slice in pixels.
width number Width of the slice in pixels.
delay number Optional. Delay override before moving this slice.
duration number Optional. Duration override for this slice.
easing string Optional. Easing override for this slice.
